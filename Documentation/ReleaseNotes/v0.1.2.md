# Yap 0.1.2

For people who professionally yap for a living.

**Release candidate: 0.1.2, build 3 — in preparation.** This candidate fixes an updater startup error found during native acceptance of the signed 0.1.1 draft. Its own packaging, notarization and native acceptance are pending. Zoom distribution approval remains pending; public downloads are not available.

## Fix

The previous candidate showed “Unable to Check For Updates” on launch because its signed-feed setting omitted Sparkle's required verification-before-extraction setting. Release configuration now enables both protections. An offline regression test invokes Sparkle's real startup validation, checks that the old configuration is rejected, and checks that the corrected configuration starts. Signed-feed and archive tamper checks remain in place.

The immutable 0.1.1 draft is superseded and must not be published. Its successful signing and notarization evidence remains historical and does not establish updater readiness. The fix does not alter existing accounts, preferences, meeting behavior or recording playback.

## Availability

Requires **Apple silicon and macOS 26 or newer**. After applicable approval and publication, install from `Yap.dmg` or expand `Yap-macOS.zip` and move Yap.app to Applications. The first public release remains subject to native onboarding, SDK and update acceptance. An actual N-to-N+1 installation has not been validated.

Yap includes native Zoom meetings, an optional Google Calendar agenda, cloud recordings, saved chat and synchronized transcripts. These features depend on your account permissions and the files Zoom saved. See the [user guide](https://github.com/grinich/yap/blob/main/Services/zoom-auth/site/guide.md), [distribution requirements](../Distribution.md), [Privacy](../../PRIVACY.md) and [Terms](../../TERMS.md).
