# Yap 0.1.3

For people who professionally yap for a living.

**Release candidate: 0.1.3, build 4 — in preparation.** This candidate fixes a Keychain migration error found while testing managed Yap sign-in in 0.1.2. Its own packaging, notarization and native acceptance are pending. Zoom distribution approval remains pending; public downloads are not available.

## Fix

Switching from a saved personal developer configuration to **Use Yap sign-in** now removes the active Zoom configuration and tokens together. If macOS denies cleanup of a protected older item, Yap still attempts the remaining scoped cleanup, reports the Keychain error, and updates the visible connection state. A failed active-vault write leaves both records unchanged. Existing Keychain protections, Google credentials and deletion tombstones are preserved.

The immutable 0.1.2 draft is superseded and must not be published. Its successful signing, notarization and static-analysis evidence remains historical. This candidate retains the corrected Sparkle startup configuration from 0.1.2 and includes the actual native meeting-gallery PNG in the project README.

## Availability

Requires **Apple silicon and macOS 26 or newer**. After applicable approval and publication, install from `Yap.dmg` or expand `Yap-macOS.zip` and move Yap.app to Applications. Managed native onboarding, broader meeting acceptance and an actual N-to-N+1 update still require validation before the first public release.

Yap includes native Zoom meetings, an optional Google Calendar agenda, cloud recordings, saved chat and synchronized transcripts. These features depend on your account permissions and the files Zoom saved. See the [user guide](https://github.com/grinich/yap/blob/main/Services/zoom-auth/site/guide.md), [distribution requirements](../Distribution.md), [Privacy](../../PRIVACY.md) and [Terms](../../TERMS.md).
