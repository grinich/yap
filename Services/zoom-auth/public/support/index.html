Report a problem

Use Help → Report a Bug in the app, or open a GitHub issue. Include the app version, macOS version, what happened, and how to reproduce it. Please remove meeting links, passcodes, credentials, and private messages from screenshots or logs before posting.

Questions and feature requests are welcome in Issues. For the project’s data handling, see Privacy. Third-party components retain their own licenses; see Third-party notices.

Privacy and security

For private account, privacy, or security matters, contact mgrinich@gmail.com. Include only the information needed to explain the issue. Do not post credentials, tokens, meeting passcodes, or private transcripts in public Issues.

Before you write

Check the user guide for connection, recordings, and removal instructions. Include the app version and macOS version, what you expected, what happened, and the steps needed to reproduce it. Screenshots with sample content are helpful.

Preview availability

The current preview is for developers and early testing. A public source repository does not grant Zoom account access or replace Zoom’s distribution review. What is ready, and what is still needed.
